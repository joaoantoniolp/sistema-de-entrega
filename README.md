# sistema-de-entrega
Atividade Prática Ferramentas de Controle e Configuração de Software
O desenvolvimento do sistema foi realizado utilizando controle de versão com Git e GitHub, seguindo boas práticas de organização e versionamento.

Inicialmente, foi criado o repositório no GitHub e, em seguida, uma branch chamada release-dev, onde todo o desenvolvimento foi realizado. A branch main foi utilizada apenas como base para integração final do projeto.

Durante o desenvolvimento, foram realizados commits incrementais, separados por funcionalidades, permitindo melhor rastreabilidade e organização do código. Entre as etapas desenvolvidas estão:

Implementação da tela de login com validação de senha
Criação do cadastro de mercadorias com no mínimo cinco campos
Desenvolvimento do cadastro de endereço com os campos exigidos
Implementação da vinculação entre mercadoria e endereço (relação 1:1)
Ajustes finais de interface e melhorias visuais com CSS

Após a finalização do sistema, foi realizado o envio do código para a branch release-dev. Em seguida, foi aberto um Pull Request para a branch main, permitindo a revisão e integração do código desenvolvido.

Por fim, foi realizado o merge da branch release-dev na main, consolidando todas as funcionalidades desenvolvidas no projeto.

Considerações

A utilização de branches, commits organizados e Pull Request contribuiu para um melhor controle do desenvolvimento, facilitando a manutenção e a evolução do sistema.
